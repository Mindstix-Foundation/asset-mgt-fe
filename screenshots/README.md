# Screenshots

This directory contains screenshots of the Pebble Asset Tracker application for use in the main README.md file.

## Required Screenshots

Please add the following screenshot files to this directory:

1. **login-screen.png** - Login page screenshot
2. **dashboard.png** - Dashboard overview with metrics and analytics
3. **asset-management.png** - Asset inventory listing page
4. **add-new-asset.png** - Add new asset form
5. **maintenance-repairs.png** - Maintenance & Repairs dashboard
6. **schedule-maintenance.png** - Schedule maintenance form
7. **add-new-employee.png** - Add new employee form
8. **reports-analytics.png** - Reports & Analytics page

**Note:** Employee management listing page screenshot is excluded to protect employee privacy and sensitive information (names and email addresses).

## Image Guidelines

- **Format**: PNG format recommended for best quality
- **Size**: Recommended width: 1200-1600px for optimal display
- **Naming**: Use lowercase with hyphens (kebab-case)
- **Quality**: Ensure screenshots are clear and readable
